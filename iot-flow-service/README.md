卡号 90154379（中国移动物联卡，ICCID 89860488192490154379）。
数据不再是"每次打开官网手动查"——由这台电脑后台定时去 `xj.mywuliankj.cn` 抓取，
手机连同一个 Wi-Fi 打开一个网页就能看，页面每小时自动刷新。

## 手机怎么用
1. 手机连上和这台电脑**同一个 Wi-Fi / 局域网**。
2. 浏览器打开 **http://10.1.14.4:8080/**。
3. 想更省事：页面里"添加到主屏幕"，以后从桌面图标点开就是一屏数据。

> IP 是路由器自动分配的，电脑重启后可能变化。想长期稳定：在路由器里给这台电脑
> 绑定固定 IP（或把 config.json 里的端口/地址记到手机书签里再改一次）。
> 当前电脑局域网 IP：10.1.14.4

## 电脑上怎么启停
- **启动（后台静默）**：双击 `后台启动.bat`，窗口最小化，日志写入 `server.log`。
- **只停这一个服务**：任务管理器里结束由 `node server.js` 启动的 node 进程，
  或命令行 `netstat -ano | findstr :8080` 查到 PID 后 `taskkill /PID <pid> /F`。
- **开机自启**：右键 `静默启动.vbs` → 创建快捷方式 → 把快捷方式拖进
  `Win+R` 输入 `shell:startup` 打开的启动文件夹。

## 配置（config.json）
首次运行前把 `config.example.json` 复制为 `config.json` 再改（`config.json` 不入库，含卡号与验证码）：

```
{
  "port": 8080,             // 网页端口
  "card": "90154379",       // 卡号
  "verify": "1299",         // 平台登录需要的"手机号后四位"（只存本机，不外发）
  "intervalMinutes": 30,    // 后台抓取间隔（分钟）
  "days": 7                 // 近 N 天用量柱状图
}
```
换卡只改 `card`；平台要是换了验证手机号，改 `verify` 后重启服务。

## 接口（页面就调这三个）
- `GET /api/flow`     → 页面数据（卡号/运营商/总量/已用/剩余/到期/状态/近 N 天）
- `GET /api/refresh`  → 立刻重新抓一次
- `GET /api/health`   → 服务与最近一次抓取状态

## 目录
- `server.js`       HTTP 服务 + 定时抓取 + 缓存
- `fetch_flow.js`   平台登录与取数（登录 → 卡信息 → 每日用量 → 订单）
- `config.json`     本地配置（不入库）；`config.example.json` 模板
- `flow.json`       抓取缓存（运行时生成）
- 前端在上级目录 `iot-flow-ui/index.html`

## 与安卓 App 的关系
这个服务是"电脑常开、手机同 Wi-Fi 看网页"的方案；不想开电脑就用 `iot-flow-app/`
里的安卓 App（手机直连平台，功能一样）。

## 说明
- 只依赖 Node.js 内置模块，不需要 `npm install`。
- 平台接口偶尔抖动时，页面会继续显示上一次成功的数据并标注时间；
  `/api/health` 里的 `error` 会写明最近一次失败原因。
- 平台若改版，可能需要同步改 `fetch_flow.js` 里的接口路径。
